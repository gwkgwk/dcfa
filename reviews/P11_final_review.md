## 4. 开发 Agent 修复方案评价

整键表的六行条件是：

| 标签 | 条件 |
|---|---|
| 引入 | 旧集空且新集非空 |
| 消除 | 旧集非空且新集空 |
| 范围扩大 | 旧集非空且是新集的真子集 |
| 范围缩小 | 新集非空且是旧集的真子集 |
| 混合 | 两侧互不包含 |
| 保持 | 两集相等，包括都空 |

空集是任何集合的子集，所以必须用“非空”把引入和扩大、消除和缩小分开。这个限制是一般集合事实，不是只为 `{b}` 写的特例。

删门算例现在写的是：确定新增区域为 `{无授权}`，整键为引入。主张 1 使用同一句话，并把范围扩大留给旧集已经非空的严格覆盖。第 44 行的 `{a}` 到 `{a,b}` 同时给出局部新增 `{b}` 和整键扩大，两个层次不再互相代替。

方案没有改威胁模型、双界差集、证据原子或冻结基线。测试只读规范并枚举小集合，不调用 `analyze` 或 `compare`。

## 5. 核心算法重新验证

固定对应上的差集没有改：确定新增仍是 `L2 \ U1`，可能新增的上界仍是 `U2 \ L1`，缓解交换两侧，共同违规用交集。解释族为空时先返回冲突。只有解释族非空且覆盖全部允许解释，才跨解释取下界交集和上界并集。

独立参照使用集合而不是测试文件里的位运算。四元集合 `{a,b,c,d}` 的 256 对子集恰好各有一个标签。三元集合上 27 个合法双界、729 个前后组合、三种区域运算的交和并，都与公式相同。

旧门未解析、新侧精确为 `{b}`、旧侧可取 `{a,b}` 的任意子集时，四个具体世界分别是引入、保持、混合和范围缩小。按规范必须返回整体未知，不能确认引入。这比“确定新增为空”更完整，也没有把分析失败写成消除。

两侧若被证明相关，无约束乘积会偏宽。探针中同一未知位在两侧必须相同，相关上界是空集，而无约束上界仍含该原子。规范第 44 行只在证据不足以约束相关性时使用全部组合。这个界限成立，有限乘积不是相关世界的最紧上界。
