# P09 运行前设计

输入是调用方指定的同一 Skill、同一入口角色的两个 P08 快照结果。设 R(t) 为域 t 的根集合，O、D 为 P08 的 owns 与 may data_flow。有向闭包包括根自身。对不同的 a,b，当且仅当 Reach(D,R(a)) 与 Reach(O,R(b)) 相交时记录有向流 (a,b)。比较两版规范化域对集合的差、交，保留每版独立见证。节点编号、行号、调用次数均不参与域对相等判断。依据为 RogueOne §4.3、§4.4；§5 默认把局部静态值归到一个 :local 域，并把建模的内建 API 当成根。[作者论文](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF)

适配只映射 P08 明确支持的根：literal → :local；内建文件 open API → builtin:file；模块声明 → import:<模块名>，后者始终附带未核验解析假设。其他节点通过闭包取得归属，不能直接用 domain 标签代替。无调用方对象时不构造 :caller。每对域给出一处共同对象、两条从根出发的路径及版本内证据。输出仅代表显式入口的可分析子集。

§4.4 的新增关系触发候选风险告警，沿用旧版作为比较参考的假设，不能推断恶意意图。已有正见证可以保留，单侧观测要在另一侧可比较且完整时才可称新增或删除；损坏输入、入口不同、未完成解释均保留未知原因。命令独立，仅用标准库读取两份 JSON。验收先写合成输入与预期，再测试方向、条件根、多路径、版本节点重排、删除、无变化与失败。
