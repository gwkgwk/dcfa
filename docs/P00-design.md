# P00 项目初始化设计

## 目的与依据

为后续单 Skill 版本对研究建立可审计的独立开发环境。本阶段的依据为 AGENTS.md 和 P00 任务书，无论文算法实现。验收对象是工程行为。

## 工程契约

- Python src 布局，运行时只用标准库。Git 管理配置、设计、代码、测试及来源登记。开发依赖在独立虚拟环境安装。
- 开发夹具由维护者手写并在 tests/fixtures/synthetic 登记；pytest 默认只发现 tests/unit。评价数据保存在仓库外单独受控目录，开发环境不挂载。运行记录命令无数据路径参数。路径约束是开发工作流约定；操作系统隔离由环境管理者保证。
- 来源登记使用版本化 JSON 清单，每条记录关联论文标识、固定论文版本和摘要、源码来源、完整提交号、原始或适配身份。校验结构和固定标识，来源真实性由人工对照原件复核。
- CLI 从仓库根目录调用。校验来源清单或创建一次 P00 基础设施自检记录。记录 UTC 时间、唯一运行号、项目版本、Python 版本、阶段、输入清单摘要、结果状态与错误码。日志写标准错误，机器结果写标准输出。失败返回非零，不产生安全判断。记录原子发布并按运行分开。
- 阶段设计与验收、第三方来源均有可复用模板。未来阶段另行提交设计并经阶段门控。
 
## 验收

验证安装入口，检查空登记及有效、无效记录，检查夹具范围、成功和失败运行、日志及输出写入异常；运行 pytest、Ruff 与 CLI 自检。提交报告，等待 P00 人工确认。
