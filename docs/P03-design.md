# P03 单 Skill SCS 接口与数据设计

输入为调用方提供的本地、静止、只读 Skill 目录快照。快照由调用方隔离并预先移除真实敏感资料。读取器检查祖先和目录项，拒绝链接、Windows 重解析点、硬链接文件和特殊文件。限制条目数、深度、单文件及总读取字节。只读取支持静态解析的材料，其余仅登记。并发对抗性替换目录不在此文件系统接口保证范围内。

extract(Path) 返回可直接序列化的单个 JSON 对象。dcfa scs DIRECTORY 输出纯 JSON 到 stdout；0 表示支持范围内完成，1 表示分析不完整或失败，2 表示参数错误。调用方将 stdout 保存至输入目录以外的文件。保留 P00 命令。输出前强制执行随包发布的 JSON Schema 校验。

§III-B 的端口、效果、操作、上下文、信任边界分别用数组表达；第六类证据内联于每项主张，包含文件、起止行、原文片段、方法和置信分值。缺少可靠属性时用 null，表示缺失证据；缺失整类证据、未识别行为、读取或解析失败用定位到文件或目录的 diagnostics 表达。文件清单及分析状态是项目封装。置信度为本地证据强度约定，尚未经校准。
