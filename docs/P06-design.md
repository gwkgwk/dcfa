# P06 阶段一表示验证设计

目标是逐项反证单快照的能力、关系和证据契约。依据为 KnotScryer §III-B/C、算法 1 第一步及 P03–P05 设计。每个样例只指定一个待检验性质，共用的封闭检查会同时排除多出的主张或边。仅使用人工书写的合成输入。先提交本设计与人工预期，再调用分析器。

人工预期保存于 tests/fixtures/synthetic/p06-oracle.json。scs 按类别与名称列出完整语义主张多重集；edges 按端点类型与名称、关系、确定性列出全部非 contains 边。归属边、文件节点、哈希和证据坐标随载体变化，不作为稳定性等价条件；S1 的两个版本须分别符合相同预期。每个 SCS 主张应有对应的图节点。另对有关用例指定参数、授权、未知或原件清单。unrepresented 记录人工从程序语义推出的真实关系；实际输出应明确显示该性质超出契约，绝不计作正向能力已实现。通过只代表固定反例符合预期。

P05 的 verified 仅证实当前原始字节与坐标可重放，possible、partial 和无运行时观测保持原义。哈希只覆盖本次默认流；无自动重命名、移动和新增文件配对，位置指针仅在本图有效。incomplete 仅为工程状态。

验收为逐例比较预期和实际投影、输出覆盖矩阵和局限、运行前置回归，最后对阶段一交付提交创建本地注释标签 phase-one-v1.0.0。外部评价、差分及意图判断不在本阶段。
