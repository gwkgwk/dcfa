# P08 单 Skill 程序流适配设计

项目已在 P03 采用 UTF-8 Python 脚本子集；没有用于估计语言占比的外部数据。本阶段以一个显式指定的 Python 入口分析一次单快照，复用有界静态读取。P07 的 JavaScript 前端、require 解析与内建对象模型不能解释 Python 绑定，Python AST、显式模块索引和按调用实例构造的对象替代它们。[RogueOne §4.2–4.3](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF)

环境映射名字到抽象对象；赋值复用身份，覆写替换绑定。常量和调用结果创建对象。显式外部模块成员产生 owns 边，外部函数及实参向结果产生可能的数据流。简单本地函数以独立参数环境解释，返回值绑定到调用点。每条边记录源码位置。open 的返回对象表示文件句柄，read/write 记录方法与参数流。仅处理直线语句、无修饰器的固定位置参数函数和同目录显式 from 导入。根目录下指定入口；分析仅遍历该入口及解析到的本地函数。外部接口按静态声明建模；不推断真实调用成功。控制流、递归、动态派发、模块初始化副作用和其他语言显式限定。未知语句停止当前路径。没有跨版本比较或策略判断。

验收采用独立合成程序检查覆盖赋值、调用隔离、跨文件证据、文件与外部接口、无流负例、动态与解析失败。使用程序级 JSON 单独交付，不消费 SCS。
