# P11 DCFA 算法规范（提案）

本文是面向同一 Skill 的研究定义。以下性质是后续实现须满足的验收命题，尚未由本阶段实验验证。威胁、策略来源和输出问题分别见[威胁模型](threat_model.md)与[研究问题](research_problem.md)。

## 1. 版本与证据

定义版本 $V=(s,v,F,A)$，s 为调用方确认的稳定 Skill 身份，v 为快照标识，F 将隔离根下相对路径映到字节串，A 是入口、格式和版本来源清单。外部可信工具契约属于 E，不混入 F。证据原子 $e=(v,path,H(bytes),span,origin,rule)$；span 指明坐标制，须能重放片段，推断还须保存前提证据。动机是区分文件位置、内容身份与语义身份。例：同一句出现两次，有两个证据原子；只改换行可改变哈希而保持能力。性质：另一版本的同一行号不能通过本版本哈希检查。边界：哈希只证明字节对应，不能证明内容为真或已执行。[P05 证据契约](P05-report.md) · [KnotScryer §III-B](https://arxiv.org/html/2610.32155v1#S3.SS2)

## 2. 单版本能力流图

$G_V=(N,E_g,typ,attr,ev,U)$ 是有限带类型有向多重图。N 区分指令出现、程序操作、工具声明、数据对象、资源与效果；这些是 DCFA 的内部表示。边记录 $(u,k,v,g,b,proof)$，k 是关系种类，g 是执行守卫，b 是数据或调用绑定。proof 区分文本/语法事实、由具名规则推出的可能关系、运行观察（本阶段无）。U 保存不能解析的绑定、守卫及覆盖缺口。父子归属与文件位置关系不可作为数据传播。以关系组合规则分别推进数据来源、控制依赖和工具调用；存在相连边不能自动贯通所有关系种类。

例：说明要求发送“该摘要”，有可信入口参数契约将“该摘要”绑定到程序参数 x，且 AST 显示 x 进入已绑定发送工具的有效载荷，才可组合成混合见证。只有工具同名或同文件出现时，保留两个实体并记绑定未知。纯文本和纯程序可各自构成候选，不强求混合路径。性质：移除桥接证据后不得继续报告已支持的混合见证。多分支路径累计守卫并要求相容；$g∧¬g$ 不可行。涉及循环时，搜索状态至少含节点、策略状态、对象绑定、来源及抽象守卫；仅在状态包含关系有证明时合并。预算耗尽进入 U。P04 的 possible 和 P05 的 verified（证据可重放）不可提升成执行事实。[KnotScryer §III-C/D](https://arxiv.org/html/2610.32155v1#S3.SS3) · [P06 已知表示缺口](P06-coverage.md)

## 3. 身份、等价与对应

区分三个层次。出现身份是 $(v,occurrence)$；角色键 $K_E(x)=(主体角色,动作族,有方向的参数角色,资源角色,效果类别)$，各分量来自同一可信命名空间或显式绑定。安全剖面 $S_E(x,c)$ 给出在 c 下的输入来源、敏感性传播、目标边界及授权/执行条件。角色键用于寻找同一个比较问题；把可变授权门写入身份键会让“删门”必然变成两个无关实体。名字和行号用于取证，不作为充分匹配条件。未知分量不充当通配符证明相等。

令 $Obs_E(x,c)$ 为能力在约定投影下允许的有类型输入、输出、效果及剖面关系集合。定义 $x≡_E y$ 当且仅当角色键相等且对每个允许上下文 $Obs_E(x,c)=Obs_E(y,c)$。这是语义定义；对任意代码不可作通用判定。有限、封闭的契约片段可用规范化或双向蕴涵给出等价证书。无法证明时返回未知。例：临时变量改名且绑定及守卫不变，预期等价；同名工具指向两个不同目的地则不据此等价。性质：在同一 E 下，语义等价具有自反、对称和传递性；局部“尚可对应”没有传递保证。[P06 语义稳定性](P06-design.md) · [RogueOne §4.3–4.4 的域级比较粒度](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF)

跨版本对应用允许解释集合 $\mathcal M$ 表示。一个解释是两侧实体或有明确聚合契约的实体组之间的部分配对，每个出现至多占一个位置。允许候选必须有同角色证据（含明确的角色映射），满足方向、类型、可信资源绑定与已知结构约束；已证不相容者排除。有稳定绑定且证据排除替代解释时要求该对出现在每个解释。只有两侧覆盖足以排除对应者时才证为单侧新增或删除。候选不足或出现拆分、合并而缺组合契约时保留开放可能，不用任意最大匹配补空缺。允许解释无解表示证据冲突，不使用空集的全称命题推出结论。例：两个同签名处理器换序且无独立锚点，可确认集合级行为保持，却无法定位哪个调用点延续。性质：重排候选不得改变一致结论；任何依赖匹配的结论须对所有允许解释成立，否则报告可能解释及差异。这是本项目提案；两篇原论文均未定义该配对。[P01 图粒度审计](reproduction/knotscryer_scope.md) · [P09 设计](P09-design.md)

## 4. 策略与违规状态

策略 $π=(id,scope,Σ,Q,q₀,δ,Bad)$。Σ 是有类型的可观察事件，状态保存必要的来源标签、对象与授权作用域。δ 只在对象关联、边种及守卫满足时推进。到达 Bad 意味着出现违反安全属性的有限前缀；释放授权须适用于该数据、目标、主体及操作阶段。具体两项策略、反例、假设见威胁模型。例：授权 A 的事件不能在追踪 B 时清除 B 的授权要求。性质：更换无关授权不会改变该对象的违规判据。无法用有限抽象保留关联时标记未知。本规范不处理一般活性或无界多次调用。[KnotScryer §III-D、表 I](https://arxiv.org/html/2610.32155v1#S3.SS4) · [安全属性与有限前缀](https://www.cs.cornell.edu/fbs/publications/EnfSecPols.pdf)

固定观察键 $k=(π,主体角色,受保护资源角色,效果角色)$，定义 $W_V(k)$ 为在约定模型下存在一条可行坏前缀的上下文集合。同一 k 可有多个独立见证。用双界 $L_V(k)⊆W_V(k)⊆U_V(k)⊆C$ 表示信息量。下界只收录有完整绑定、策略条件与模型内可行性证书的上下文；上界含有尚不能排除的上下文。抽象图的 may 路径默认只是候选，不自动进入下界。缺少可信上界推导时取整个作用域 C；仅在支持子集覆盖封闭且有排除证书时才能移出 U。于是 c∈L 表示模型内存在违规行为，c∉U 表示在声明范围内排除，其他取未知并记录候选或缺口。它们都不表示用户确实经历过该事件。例：发送边存在但对象授权不明，c 留在 U 内，不入 L。性质：补充一致证据可令 L 扩大、U 缩小；改变模型或修正错误证据则须重新分析。[P05 证据语义](P05-report.md) · [KnotScryer §III-E 的结构与验证之别](https://arxiv.org/html/2610.32155v1#S3.SS5)

## 5. 变化、不确定性与差异位置

对每个允许对应 m 将前后观察键投影到共同坐标。在固定 m 下，新增违规上下文的保守下、上界分别为 $L_2∖U_1$、$U_2∖L_1$；缓解的界由交换两侧得到；共同违规的界为 $L_1∩L_2$、$U_1∩U_2$。先核实两侧可比；环境或身份不可比时返回不可比较。可比但解释族为空时返回证据冲突，不计算界。只有非空且覆盖全部允许解释时才跨 m 取下界交集、上界并集；未穷尽且无覆盖证明时保留开放解释和未知，不能把截断误报为无解。比较要求上下文、工具契约、策略版本及抽象精度可比；缺口保留在上界。新旧都没有输出候选不足以说明等价。逐上下文的新增、缓解和共同区域，与整键标签分别记录。对有限谓词可枚举互斥上下文区域或作符号蕴涵；可满足性未知要传播，不能按 false 剪枝。

**整键标签表。** 令 X、Y 为可比且对齐后同一键的两侧真实违规上下文集，a、b 是不同上下文编号。这里的 a、b 不预设授权真假。每行条件对完整集判定，表的最后两列给出最小实例。

|整体标签|必要且充分条件|旧 X|新 Y|
|---|---|---|---|
|引入|X 为空且 Y 非空|∅|{b}|
|消除|X 非空且 Y 为空|{a}|∅|
|范围扩大|X 非空且 X 是 Y 的真子集|{a}|{a,b}|
|范围缩小|Y 非空且 Y 是 X 的真子集|{a,b}|{b}|
|混合|X 与 Y 互不包含|{a}|{b}|
|保持|X 等于 Y（包括两者均空）|{a}|{a}|

**判定约束。** 每个具体世界恰落入一行。证据只有双界时，须在所有可行解释及其允许的真实集合对上得到同一标签才能确认；部分界不能唯一决定整体标签时返回整体未知，仍发布有证据的逐上下文区域。证据不足以约束两侧相关性时，考虑双界内所有组合，不默认同一未知在两侧取同一值。例：X={a}、Y={a,b} 时新增区域为 {b}，整体为范围扩大。若两个独立键分别引入与消除，则输出两条带各自键的记录，不相抵。

最小算例：C={有授权,无授权}，旧版强制授权且保密策略仅禁止未授权发送，故 $L_1=U_1=∅$；新版可在未授权时发送并有契约见证，$L_2=U_2=\{无授权\}$，确定新增区域为 {无授权}，整体标签为「引入」。若旧版门未解析则令 $L_1=∅,U_1=C$，同一新版见证只支持可能新增，整体未知：旧集既可能为空，也可能等于新集。性质：交换版本应交换新增与缓解；一致且精确的自比较不产生新增。粗略双界自比较可能产生虚弱上界；若已证是相同字节及同一确定环境，可使用同一模型解释的恒等证书消除该伪可能。非相同字节须有逐键观察等价证书：固定环境、覆盖、可行对应与策略，证明映射保持绑定、守卫与策略可见轨迹，且反向也成立。仅对覆盖的键可推出保持。换行若改变字节，原件位置须在各版本分别重放；词法空白位于字符串内、缩进有语义、名字被遮蔽或动态查找未解析时，不得用表面规范化颁发证书。不能证明时保留未知。此变化算子是研究设计，区别于 P09 对域对求差。[RogueOne §4.4](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF) · [P10 验证范围](P10-report.md)

修改位置集合 D 来自两份快照间可重放的编辑记录，每项含两侧哈希和区间，插入或删除的一侧允许为空。先将新旧见证与其守卫、授权和排除证书的依赖追溯到原始位置。定义支持关联 $Rel(d,w)$ 为 d 触及 w 或其旧版排除证书的已验证语义前提，且重放能说明该前提如何变化。只靠行号接近或同文件编辑不成立。更强的模型内解释：在可合法重建且契约固定的混合快照 $V_1⊕J$ 中，若 $J⊆D$ 足以复现指定变化且所有真子集均不能，则 J 是一个最小充分编辑集；任一子集结果未知时不得声称已证最小。可能存在多个这样的集合，未经穷尽不得称某编辑为必要原因。混合快照无效、匹配含歧义或依赖不全时只报告支持关联及限制。此为 DCFA 拟议的静态反事实检查，不是提交者动机或现实因果的证明。

例：同次修改删除发送前授权门并调整 README 空白。若只恢复门就在模型内排除该变化，而仅去除空白仍产生变化，且各重建均有效，则单项删门可为最小充分集。若另有独立路径仍产生同一违规，恢复某条路径的门不能证明总体缓解。性质：添加与见证及旧排除证书都无依赖的编辑，不应自动获得支持关联；旧证据不可由新版同名文件替代。[RogueOne §4.4 的集合变化起点](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF) · [P05 双向证据索引](P05-design.md)

## 6. 审核门与后续可验证性

拟议流程为校验同源版本和环境 → 分别建图并登记缺口 → 求有证据的允许对应 → 按策略导出两侧界与见证 → 跨对应求变化界 → 重放证据与可行编辑集。任一步失败须记录版本、受影响的观察键、原因和已取得的前缀。证据账本须区分原件事实、规则推断、假设和未来独立观测。只有闭包、守卫与根域假设相容时才可使用程序流；不能把冻结基线的候选当作 DCFA 的 ground truth。

人工审核至少检查：①固定上下文与两项安全属性是否符合研究目的；②跨模态绑定所需证据能否由可控输入提供；③等价、对应和未知的区别能否在重复实体例上重放；④双界在旧侧失败、守卫矛盾和既有违规下是否保守；⑤删门加无关编辑、多个充分编辑集是否得到不同解释。依赖于当前提取器尚无的跨语句、任意自然语言、授权执行或条件精度的性质仅列为研究假设。P11 交付形式化设计。P12 已实现第 3 节在有限分析者契约下的实体对应与观察投影。P13 已实现第 4 节的单上下文策略求值；P14 已实现第 5 节的有限上下文差分；P15 已实现基于原件的位置关联及绑定常量参数的有限语义关联。P16 已集成这些子集。反事实重建及最小充分编辑集仍未实现。
