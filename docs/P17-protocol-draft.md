# P17 外部评价协议草案（样本接触前）

状态：待核验 DCFA 正式冻结记录。数据审核、样本划分、数据冻结、预测与统计均未运行。本文件记录样本接触前的设计，不构成数据冻结清单。

## 样本与审核

实验单位为同一 Skill 的有方向版本对。保留来源、获取日期、稳定项目标识、两侧发行/提交标识、时间顺序、上游出处和授权信息。按相对路径、字节长度、逐文件 SHA-256 排序，以规范化 JSON 再计算两侧树摘要。保留单文件和整树指纹。拒绝外链、路径逃逸和特殊文件，全部材料只读静态核查。无法取得任一原件、无法确认方向或同源性的配对记入排除台账并记录原因。

两名独立标注者在不看预测的情况下，分别记录旧新侧目标行为、对应原件哈希和精确位置、授权与环境假设、变化依据、意图证据出处及置信边界。第三人裁决分歧，保留初始判断。事件发生日期及影响版本必须与原件相符；单侧告警、漏洞通告或模型判断本身不足以确认恶意更新。

分别记录意图轴（确认恶意、支持良性、未确定）与逐项安全变化轴（新增/加剧、保持、缓解/解除、无已知目标风险、未知）。配对汇总采用以下固定优先序，同时完整保留各行为的独立状态：
1. 有独立意图证据且该更新引入相应恶意行为，记确认恶意更新。
2. 有证据确认新增或加剧且未确认恶意意图，记安全退化；保留意图未知。
3. 已证同一既有风险持续且范围未变、无另外确认的退化，记已有风险保持。缺失旧侧证据不能作保持证据。
4. 有积极良性证据且行为差异已审核，无新增退化或持续风险需要单列，记良性更新。记录改善型子类。
5. 其余及影响归类的未决冲突记标签不确定。若同一配对同时有缓解和退化，分项保留，不能相抵。

## 独立性与冻结工件

先登记开发者、审查者、模型调试、提示词设计和公开案例的接触历史。构建连通分组，依据同一 Skill、共同祖先/派生项目、共享任一版本树、相同更新及人工核实的近重复。近重复候选由去注释/排版的代码标记与文档词片段检索，再以来源和行为证据核实。保存候选、裁决和理由。开发样本及其整个关联组标为开发或已接触；接触史不清楚者单列。最终盲测只含有独立性依据的未接触组。相同配对去重；共享版本的相邻更新保持同组。冻结后不得用最终测试组调参、反选样本或选择最优报告口径。

冻结清单分三份：保管方持有的来源/证据/标签台账；不含标签、来源分类、暗示性外层路径的预测清单（随机不透明 pair_id、两侧原件树与摘要）；评估方持有的分组、划分、排除及接触历史台账。冻结时分别归档带版本号的内容、摘要、审核者、日期与算法版本。保存实际原件内容，禁止重写 Skill 内语义以抹去线索。记录原件自身显露标签的局限。开发集和最终集应分别报告真实样本数与组数。

## 预测隔离与可运行性门槛

预测进程只读开放预测清单、对应的原件及锁定的分析配置；不挂载来源台账、标签、审查证据或评估目录，禁网。独立保管者用哨兵文件和访问日志核查边界。双方法使用同一预测清单和受控资源。固定每对每方法单进程、300 秒墙钟和 2 GiB 内存，独立临时目录、无跨组缓存。原始输出和失败日志先签封并计算摘要，再由独立评估程序用 pair_id 联接标签。禁止执行不可信 Skill。

P16 需要外部有限契约。契约提供者只可见预测阶段允许的材料；策略、观察域、授权来源和编制规程必须先锁定并记录工时。不能从行为真值、事件报告或目标修改行构造查询和授权。若缺少独立可用的契约来源，DCFA 应记录未知或不可运行，并单列人工辅助设置。正式运行前在开发数据上验证物理隔离及两方法正常入口，锁定配置、依赖、适配器和标签映射。

## 统计与比较

主要终点为更新是否存在有证据的新增/加剧策略违规；依分项安全变化定真值。恶意意图单独报告，未经证实意图的退化样本不作确定恶意或确定良性。DCFA 的阳性要求预定观察域内至少有一个确定新增违规区域；仅有可能新增、不可比或缺报告且无确定新增时弃判。只有预定观察域充分覆盖且所有新增上界为空才作阴性。RogueOne-style 使用冻结方法原生新增流告警作为代理预测，报告其与策略终点的语义差异。不得将任一告警作为意图证明。

对确定真值报告 TP、FP、TN、FN 与阳性/阴性各自的弃判、失败、超时、未执行数。主要比较使用同一批最终配对，报告全分母阳性检出率 TP/全部真阳性、全分母假警率 FP/全部真阴性及有效预测覆盖率；另报已决子集的 precision、recall、F1 和分母。缺预测不计正确；全分母假警率必须与覆盖率一起解读。分母为零报告 NA。真值不确定者单列数量、预测分布及原因。按五类标签和程序/指令/混合更新分层描述；程序共同支持域另列，不替代全样本结果。

方法差异在相同配对上计算；以同源连通组为重采样单位，配对保留两方法结果，固定种子 1701，重复 10000 次，报告指标差与百分位 95% 区间、有效重复数。有效独立组少于 10 或有效重复少于 9500 时仅给描述统计并标注不稳定。同步给出逐组结果，避免单一大项目掩盖异质性。证据定位仅在有独立人工位置真值的子集评价，按版本、路径、相交行分别核对；无可靠定位真值时不计算。正式评价前必须签认协议，任何后续修订保留版本、时间及是否已揭盲。
