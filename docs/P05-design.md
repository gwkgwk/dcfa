# P05 原始证据映射契约

输入为已校验 p04.1 图（内嵌 p03.2 SCS）、本地静止且已脱敏的单 Skill 快照，以及可选的分析者原始绑定 JSON 文件。方法依据是 KnotScryer §III-B 的逐主张证据，以及 P04 已定义的带依据指针的投影。以下字节哈希、位置重放、双向索引和缺证状态是项目扩展。输入指针仅在当前快照内有意义。[P01](reproduction/knotscryer_analysis.md) · [P04](P04-design.md)

对安全枚举得到的普通文件原始字节 b 计算 SHA-256(b)，换行转换及 UTF-8 BOM 去除均发生在哈希之后。继承 P03 的不可变快照假设、链接检查和读取预算；仅登记文件可在独立的有界预算内读取字节用于哈希，内容不解释。永远不根据 SCS 声称的路径打开文件。找不到材料、预算截止或解析位置不符时保留缺证。

对每个能力，在整个原文的声明／指令／脚本上下文中重放 P03 提取。仅当主张、位置、片段与提取方法完全匹配且出现次数一致时建立验证关系。行号从 1 起且含首尾。Python 额外保存实际 ast.Call 起止 UTF-8 字节列（从 0 起，尾列开区间）；同一行重复调用用 P03 源码顺序区分。材料重排后的旧坐标不能靠全文搜索重新认领。重排后重新提取的快照可独立映射。哈希证明的是提供给 P05 的字节；p03.2 未保存原始哈希，故无法证明历史字节完全一致。

将来源分为 skill 快照和可选 analyst 绑定文件。绑定文件必须逐项等于图内绑定表，保存每项声明的字符区间（解码后从 0 起、尾开）、原文、文件哈希及分析者依据；该证据只证明声明存在。未提供文件则不能用内嵌自由文本代替原件。

以 SCS 组及数组位置为能力实体，以节点 ID 及边数组下标为图实体，以图原始 evidence 指针向上找到所属能力或直接文件／绑定。结构根以必需文档的文件级证据表示快照入口；文件级证据用全文件字节区间（空文件允许 [0,0)）。每条边取 P04 要求的全部端点来源，保留原关系和 certainty。单一来源缺失时不允许将整条边升级为已验证。目标记录列出原始依据和不确定性；正向索引按文件记录能力、节点和边，反向索引按能力、节点、边列出全部证据。内部元数据、无操作归属的文件和绑定允许直接映射。

接口 build_index(graph, root, binding_file=None) → p05.1 JSON；CLI evidence GRAPH DIRECTORY [--bindings FILE]。无效图或非法外部文件格式返回错误；合法的缺证结果输出 JSON 并返回 1。验证仅指原始材料可回溯，保持 P03 覆盖状态和 P04 运行时未观察的结论。独立测试包括文件及语句重排、同一行重复、伪造路径／语义／位置、命名空间、跨来源、缺少绑定、哈希和双向一致性。
