# P10 基线独立验证与冻结

问题为单个 Skill 的程序更新能否在固定 P08/P09 子集内得到事前规定的域对差分。oracle 在 18fb2c3 提交，运行后没有调整。真实临时文件经 analyze(directory, entry) → compare(before, after)，每例分别断言两侧实际流、五个集合、候选、完成状态及诊断。下表只有列出的域对非空。L 表示 :local→import:api，AB 表示 import:a→import:b。

|版本变化|应具能力与实测|论文边界与 Python 适配影响|缺陷判定|
|---|---|---|---|
|完全相同|保持 L，无告警|域对自比较；只比较指定入口|符合预期|
|变量重命名|保持 L，无告警|论文比较域而非变量名；本例由 Python 名字绑定保留对象身份|符合预期|
|等价重构|普通导入与直接调用改为别名导入及拆分赋值；保持 L|验证同一模块同一成员的两种受支持写法；不能推广到任意重构|符合预期|
|合法功能新增|增加同模块预览调用；保持 L，无告警|域对相等会忽略同域功能变化。跨域合法功能也可能触发候选；没有合法性判别器|符合预期|
|新增跨域流|原来只共现的两个外部模块产生参数依赖；新增 AB，唯一候选|§4.3 两种可达集相交；模块根依赖未核验导入假设，静态结果不证明执行|符合预期|
|删除流|反向更新删除 AB，无告警|§4.4 关注新增，删除是本项目额外报告的集合；两侧均完整|符合预期|
|仅改自然语言|Python 文件相同，保持 L，无告警|原方法面向程序；适配器要求存在 SKILL.md，但不解释正文|符合预期|
|执行条件变化|无条件调用移入 if；新版 partial，L 留在 unresolved_before，无删除或告警|不是论文固有的条件分析上限。P08 直线子集在 unsupported_If 停止；P09 无法认定旧流已消失|记录适配局限|
|无法解析操作|已有流之后调用未绑定 callback；新版 partial，保持 L，无告警|原方法依赖抽象解释质量；P08 对 unresolved_Name 停止并保留前缀，后续未知|记录适配局限|

依据为 RogueOne §4.3 的有向可达交集、§4.4 的新流集合，以及 §5 的默认局部值归一化。这里验证有限语义性质，不估计生态召回率、误报率或 DCFA 优势。[作者论文](https://yinzhicao.org/RogueOne/RogueOne-ICSE24.PDF)

## 冻结与复核

冻结标记 rogueone-style-baseline-v1.0.0 指向本报告所在代码提交。使用 git rev-parse rogueone-style-baseline-v1.0.0^{} 获取精确 SHA。代码配置随提交固定：Python AST 直线子集，单一 :local、builtin:file、声明模块域；对象上限 4096，调用深度 24；读取器单文件 32 KiB、总计 256 KiB、最多 256 项、目录深度 12。P09 两侧采用同一根与闭包规则，无额外阈值。Windows，项目 Python 3.14.0a5、pytest 9.2.0，基线运行只使用标准库。切换解释器可能改变标准库名字表。输入是否来自同一 Skill、配置与入口角色仍由调用者保证。

新增 P10 设计、固定输入及人工 oracle、独立测试和本报告。入库冻结的 P08/P09 实现和专项回归此前在工作区中已验证，本轮未更改其行为。没有读取外部评价集。工作区执行 python -m pytest -q tests/unit/test_p10_baseline.py 为 9 passed；全套 python -m pytest -q 为 142 passed，含工作区既有 P07 审查测试；ruff check . 通过。冻结复核针对 P08/P09/P10 专项套件。九项均与独立预期相符，本轮未发现需修复的实现缺陷；冻结用于后续公平比较，停在 P10。
